步骤与预期：

1. 在人脸分析同意页选择“暂不使用人脸分析”；预期不打开照片选择器，不上传照片，并进入挑战中心。
2. 选择一个模板并创建挑战；预期只出现一组进行中挑战。
3. 打开挑战详情并完成今日打卡；预期成功后按钮显示“今天已完成”，云端当天只有一条记录。

## 2. 合格照片完成分析并清理原图

**旅程：**同意 → 选择合格照片 → 分析 → 原图删除 → 身份卡 → 推荐挑战。

前置：测试账号无旧同意；使用已授权、非真实用户的合格单人正脸照片；生命周期告警和存储核查可用。

步骤与预期：

1. 明确同意人脸分析并选择合格照片；预期生成不超过 1600px 的 JPEG，基础质量通过。
2. 开始分析；预期服务端只处理本次照片，生成身份卡且不保存原始关键点。
3. 核查精确云文件 ID 的存储删除成功回执；预期分析完成后立即安排清理，异常路径在承诺期限内完成，不能只看业务记录状态。
4. 打开身份卡并进入预选的推荐挑战；预期报告保持参考性表述，不出现医疗、效果或排名结论。

证据：分析任务/报告编号、模型与规则版本、精确文件 ID 的删除回执、身份卡和推荐挑战页面；证据中打码用户标识。

## 3. 低质量照片继续并保存参考海报

**旅程：**低质量照片 → 继续分析 → 参考报告 → 保存身份海报。

前置：相册中有一张可稳定触发低质量提示的授权测试照片；相册写入权限分别测试允许和拒绝。

步骤与预期：

1. 选择低质量照片；预期同时看到“重新拍一张”和“仍用这张照片分析”。
2. 选择继续；预期报告明确标记为参考结果并保留质量问题，不暗示准确性或效果。
3. 生成身份海报并允许相册权限；预期海报成功保存且页面不丢失。
4. 重新执行并拒绝相册权限；预期保留页面、给出授权/重试入口，不声称已保存。

证据：低质量提示、参考报告、允许/拒绝相册结果和实际相册文件。
