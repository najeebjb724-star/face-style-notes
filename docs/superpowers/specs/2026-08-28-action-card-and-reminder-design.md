# 行动卡与提醒系统设计

## 目标

把报告中的固定“30 天行动卡”改成无需用户编写内容的轻量行动系统：系统依据本次报告推荐三张卡，用户选择一张后，可选择提醒节奏、完成关键节点打卡，并把提醒加入手机日历。

## 产品流程

1. 报告生成后展示三张可选择的行动卡。
2. 每张卡明确说明推荐原因、具体动作、耗时、成本、观察指标和停止边界。
3. 用户点击卡片即选中并保存在当前浏览器，不需要填写文字。
4. 用户从“第 1/7/30 天”“每周一次”“暂不提醒”三种提醒卡中选择一种，并从 08:00、12:30、21:30 三个时间卡中选择提醒时间。
5. 页面展示第 1、7、30 天三个轻量打卡节点，完成状态保存在本机。
6. 用户点击“加入手机日历”时，网页版下载标准 `.ics` 日历文件；未来迁移微信小程序时，将同一数据结构接入 `wx.addPhoneCalendar` 或 `wx.addPhoneRepeatCalendar`。

## 卡片生成

- 三张卡分别覆盖：当前主要造型目标、基础稳定动作、同条件复盘。
- 卡片文案来自现有测量结论和问卷，不增加颜值评分、缺陷判断或医疗承诺。
- 一次只允许选择一张卡，选择状态有明显的视觉和无障碍反馈。

## 状态与隐私

- 仅保存行动卡 ID、提醒模式、开始日期和节点完成状态。
- 不保存照片、关键点或面部测量数据。
- 使用 `localStorage`；不可用时保持当前会话可操作并提示用户。
- 重新做人脸分析不主动删除已保存的行动进度，用户可在行动区清除进度。

## 日历边界

- 网页不能直接申请微信小程序权限，因此提供 `.ics` 下载作为可用的网页实现。
- 第 1/7/30 天模式生成三个单次事件；每周模式生成一个持续四周的重复事件；不提醒模式隐藏日历入口。
- 页面明确说明“不会读取你的日历；是否导入由系统日历确认”。

## 验收标准

- 完整问卷报告始终返回三张结构完整、ID 唯一的行动卡。
- 卡片、提醒模式和节点都可直接点击选择，无自由文本输入。
- 刷新页面后可恢复已选卡片、提醒模式和打卡状态。
- `.ics` 内容包含所选卡片标题、日期和有效的日历结构。
- 现有人脸测量、照片质量覆盖、报告导出及 18 项测试不回归。
