# 微信小程序发布检查清单

最后更新：2026-09-21

## 结论

**发布门槛：CLOSED / BLOCKED。** 当前只能说明本地工程与自动化测试状态，不能说明候选版本可上传、可提审、可部署或审核员可独立完成流程。

状态约定：`[x] LOCAL PASS` 仅限本机证据；`[ ] NOT RUN` 尚未执行；`[ ] BLOCKED` 有明确前置缺口。

## 放行阶段

1. **阶段 1：上传前阻塞。** 完成本地证据、微信注册资料、目标环境部署、隐私/可靠性 P0 和运行时环境选择；这一阶段全部通过后才可上传体验版。
2. **阶段 2：上传体验版。** 上传候选版本，记录版本说明、成员权限和审核账号。上传本身不是提审放行。
3. **阶段 3：体验版执行。** 在该体验版上完成审核员路径、五条 E2E、设备/网络/权限/显示矩阵并留存证据。
4. **阶段 4：最终签字与提审。** 阶段 1–3 的同一候选版本均有真实证据后，才可完成签字并提交审核。

任何阶段未通过都保持 `CLOSED`；不得跳过体验版执行而预先签字或提审。

## 阶段 1：产品边界核对（P0/P1）

- [ ] 文案只称“个人造型参考”，无医疗诊断、身份识别、疗效/效果承诺或颜值排名。
- [ ] 小程序未采集网页版问卷时，不展示问卷专属护理方案。
- [ ] 挑战/结营对照照明确为本地临时使用；在云桥完成前不声称已云端保存。
- [ ] 手机日历明确为逐日普通事件；不声称系统重复日程。
- [ ] 订阅发送为最多尝试一次；`manual_review` 在与微信侧核对前不得自动重发。
- [ ] 分享预览七天到期；相册图片、截图和他人另存副本无法远程删除。
- [ ] 清空数据不是注销账号；重试/核查记录可能在有限期限内保留；未来继续使用会生成新数据。
- [ ] 已提交给微信的提醒无法撤回；删除只影响后续任务。
- [ ] 依赖安全审计已完成：固定 TensorFlow/Express 依赖升级验证或书面风险接受及镜像构建隔离措施有记录。
