# 人脸分析单独同意文案

## 选择照片之前

为了生成本次美学身份卡，我们需要上传你主动选择的一张人脸照片，分析照片中的二维几何关系。结果会受光线、角度和拍摄条件影响，仅供个人造型参考，不用于医疗诊断或身份识别。

分析源照片正常在处理结束后立即安排删除；异常情况下应在上传后 30 分钟内进入到期清理。存储服务故障可能导致实际删除延后，系统会重试并保留待处理状态，直到确认成功。照片不会因为你同意分析而自动成为挑战照片。

生成的身份卡会保留，供你查看和主动删除。你可以在“我的”撤回人脸分析同意；撤回会停止未完成分析并安排源照片清理，已保存的身份卡不会自动删除。你也可以分别删除身份卡或清空全部业务数据。

按钮：**同意并选择照片** / **暂不使用人脸分析**。不应默认勾选同意；拒绝后仍可使用其他可用功能。

## 撤回确认

撤回人脸分析同意，停止未完成的分析并安排源照片清理。已保存的身份卡和挑战保留；以后分析需要重新同意。

第二次确认：确认后将开始处理，已删除的记录无法恢复。是否继续？

## 挑战照片另行说明

挑战照片需要另行说明用途并授权，默认在挑战完成七天后安排清理，或在你删除挑战时安排清理。当前挑战照片上传链路仍未接通，上线前不得将其描述为已完整可用。
